# Daily

One note per day, named `YYYY-MM-DD.md`. The most recent one is the first thing the agent reads every session, so it is written state-first: what is true now, what is open, what happened, each in one or two lines with a link to the detail.

When a day's narrative outgrows those stubs, the full account moves verbatim to `log/YYYY-MM-DD-log.md` (see [[log/README|the log folder]]) and the daily links to it. The daily answers "what is true now"; the log answers "how it happened".

`2026-01-15.md` is a sample showing the section skeleton. Delete it when you have real days.
