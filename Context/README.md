# Context

Who you are, how you work, what you are aiming at, and what tools you use. The agent reads `me.md` at the start of every session; the rest it reads when a task calls for it.

| File | Holds |
|---|---|
| [[me|me.md]] | Identity, role, working style, communication preferences. The one file every session loads. |
| `strategy.md` | Goals and priorities. Projects link back here so every action traces to a stated goal. |
| `infrastructure.md` | Tool stack, integrations, and the table of where external code lives (repos outside the vault). |

Add files as your context grows (a glossary, a people index, a brand or voice file). Each gets a row in this table and in the root `CLAUDE.md` Knowledge Routing table.

Only `me.md` ships filled in as a template. Create the others when you have content for them; do not pre-create empty files.
