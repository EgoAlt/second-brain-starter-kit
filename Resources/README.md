# Resources

Reusable reference material: frameworks you have absorbed, prompts you reuse, templates, and knowledge pages on topics that outlast any one project. If a note would still be useful after the project that prompted it is archived, it belongs here.

| Subfolder | Holds |
|---|---|
| `library/` | Knowledge pages, grouped by topic. Each topic folder has an `index.md` linking every page in it. |
| `operator/` | The operator's own state files, starting with [[operator/health-backlog|health-backlog.md]]. Written by the scheduled agent, read by you. |

Add `prompts/`, `templates/`, or `frameworks/` when you have content for them.

`library/sample-topic/` holds two demo knowledge pages on an invented hobby topic. They show the page standard (Summary line, wikilinks woven into prose, a callout, a Related pages section). Delete them when you have real pages.
